## 📊 Core Concepts & Entity Classification

The decision engine inside the book evaluates information based on four foundational data pillars to match the correct visual family without distortion:

### 1. Data Comparison (Discrete Categories)
*   **Target Objective:** To compare independent, non-continuous values across distinct entities.
*   **Primary Matches:** Column Charts, Horizontal Bar Charts.
*   **Technical Constraint:** Y-axis baseline must strictly anchor at zero to maintain graphical integrity and prevent visual distortion.

### 2. Temporal Trends (Continuous Changes Over Time)
*   **Target Objective:** To display continuity, cycles, and rate of change across specific time intervals.
*   **Primary Matches:** Line Charts, Area Charts.
*   **Technical Constraint:** Temporal progression must strictly move horizontally from left to right on the X-axis.

### 3. Compositional Breakdowns (Part-to-Whole Proportions)
*   **Target Objective:** To communicate the relative size of components making up a single continuous whole.
*   **Primary Matches:** Donut Charts, Stacked Columns, Hierarchical Treemaps.
*   **Technical Constraint:** Multi-categorical segments should be restricted to a maximum of 5 categories to preserve readability.

### 4. Continuous Relationships (Statistical Correlations)
*   **Target Objective:** To map two numerical variables on a coordinate grid to identify statistical dependencies or outliers.
*   **Primary Matches:** Scatter Plots, Heatmaps, Bubble Charts.
